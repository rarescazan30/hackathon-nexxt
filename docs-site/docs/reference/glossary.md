# Glossary

| Term | Meaning |
|---|---|
| **Bani** | 1/100 of a leu (RON). Every amount in the code is an integer number of bani. |
| **Pillar I** | The state pension (CNPP). Estimated from salary and contribution years. |
| **Pillar II** | Mandatory private pension: 4.75% of gross salary, paid by the employer through payroll. |
| **Pillar III** | Voluntary private pension (ASF-regulated), tax-deductible up to 400 €/year. Where LifeGrowth sends money. |
| **Replacement ratio** | Income at 65 ÷ today's net salary ("79% of the life you have now"). |
| **Days of freedom** | Days of retirement your savings pay for at 65, in today's money. |
| **Real return** | Growth above inflation (~2.2% a year here). |
| **Round-up** | The difference between a card payment and the next step (5 RON): 12.30 → 15.00 gives 2.70. |
| **Jar / month** | One month's counter: round-ups + salary share (`monthly_jars`). |
| **Offer** | The month-end question: "Add X RON to your Pillar III?" |
| **Hold / float** | The month the accepted money stays with the banking partner before Pillar III; its interest is the revenue. |
| **Tier / slot / level** | 5 lifestyle tiers × 4 slots (home, transport, food, extras) = 20 levels. |
| **XP** | Points from days of freedom added (10 per day) and streaks. |
| **Open Banking / PSD2** | EU rules that let apps read bank data (AIS) or start payments (PIS) with the user's consent. |
| **SetupIntent / PaymentIntent** | Stripe objects to save a card / charge it. |
| **3-D Secure (SCA)** | The bank's extra confirmation of a card payment. |
| **RLS** | Row-level security: database rules that limit each user to their own rows. |
| **Server Action** | A server function a button calls directly (Next.js). |
